# yacinedaher.github.io

Personal portfolio of Mohammed Yacine Daher, served with GitHub Pages at <https://yacinedaher.github.io>.

Built with Jekyll, which GitHub Pages runs automatically on every push: there is nothing to install.

## Where things are

| To change | Edit |
|---|---|
| Sidebar, top bar, footer | `_layouts/default.html` |
| Menu entries | `_data/nav.yml` |
| Projects (title, year, tags, link) | `_data/projects.yml` |
| Home page | `index.html` |
| Colours, fonts, spacing | `assets/css/style.css` |
| Resume, photo, screenshots | `assets/` |

## Writing a blog post

Add a Markdown file to `_posts/` named `YYYY-MM-DD-title.md`.
